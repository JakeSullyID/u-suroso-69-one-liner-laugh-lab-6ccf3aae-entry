# One-Liner Laugh Lab Entry

## The Joke
This entry answers the prompt regarding the excuse a robot vacuum gives after eating a sock:
> I didn't eat your argyle sock; I granted it political asylum in my dustbin.

## Character Count
The one-liner is exactly 75 characters long, which is well under the 200-character maximum limit. Every word works to elevate a mundane household mishap into bureaucratic absurdity.

## How to Run
Run the program using Node.js:
```bash
node --import tsx main.ts
```
The script will write the entry without a trailing newline to `entry.txt` in the directory specified by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`).
